# Published results — thesis archive (frozen)

These files are the exact evaluation artifacts cited in the master's thesis. They
are **read-only history**. Nothing in this directory is regenerated by any command
in this repository; live re-runs land in `evaluation/outputs/runs/<timestamp>/`.

## Provenance

Produced during the thesis writing period against a local Docker PostgreSQL and
the OpenAI API, over five synthetic scenario windows derived from CICIDS 2018
traffic characteristics. All hostnames in the data are synthetic
(`site1.org` … `site4.org`); no operational data from the deployment environment
is present.

| File | What it is |
|---|---|
| `FINAL_three_group_results.csv` | The headline table: 5 windows × 3 groups × 3 dimensions |
| `geval_scores_v3_mean3runs.csv` | Groups A and C, mean of 3 judge runs, with per-dimension rationales |
| `groupb_scores.csv` | Group B, same rubric and judge |
| `all_reports.json` | Generated reports for Groups A and C, plus the aggregated context each was given |
| `group_b_reports.json` | Generated reports for Group B |
| `window_{1..5}_reports.json` | Per-window slices of `all_reports.json` |
| `geval_scores.csv` | Superseded — an earlier rubric (accuracy / relevance / readability) |
| `geval_scores_v2.csv` | Superseded — single-run predecessor of v3 |

## Known drift from the current code

**These numbers cannot be reproduced by running the current harness.** The
`aggregated_context` recorded in `all_reports.json` has the keys

    total_blocked_events, security_summary, infrastructure_health

whereas the aggregation code as it stood at the end of the thesis emits

    report_generated_at, period, security_summary, infrastructure_health, historical_trends

`total_blocked_events` is produced by no code that survived into the repository.
The aggregation was edited after the experiment ran and the results were never
regenerated. A different context shape yields different reports and therefore
different scores.

This directory preserves what the thesis actually reported. The reconciled
harness — and results it genuinely reproduces — live under
`evaluation/outputs/runs/`. See `docs/findings.md` for the reconciliation and for
what the drift revealed.
